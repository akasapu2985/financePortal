# financePortal Frontend

Vite + React + TypeScript scaffold for the financePortal dashboard.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — run the TypeScript build and create a production bundle
- `npm run lint` — run ESLint

## Notes

- The app entry point includes a shared React Query client.
- The Vite dev server proxies `/api` requests to `http://localhost:8000`.
- The `@/` alias resolves to `src/`.
